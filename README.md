# mi-landing

Landing page SPA desarrollada por **Martinez Matias Jose**, construida con React, TypeScript y Vite.

## Requisitos

- [Node.js](https://nodejs.org/) 24 (la versión está indicada en `.nvmrc`)
- [pnpm](https://pnpm.io/)

## Cómo descargar y ejecutar el proyecto

1. Cloná el repositorio:

```bash
   git clone https://github.com/Programati/mi-landing.git
```

2. Entrá a la carpeta del proyecto:

```bash
   cd mi-landing
```

3. Instalá las dependencias:

```bash
   pnpm install
```

4. Iniciá el servidor de desarrollo:

```bash
   pnpm dev
```

5. Abrí en el navegador la URL que aparece en la terminal (por defecto, `http://localhost:5173`).
